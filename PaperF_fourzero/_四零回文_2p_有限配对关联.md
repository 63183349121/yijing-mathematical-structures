# Finite-population pair association for n=2p

For the deterministic candidate set indexed by 1 <= i < j <= p-1:

    mu = N4/N,
    kappa = C(N4,2)/C(N,2) - mu^2.

This is a finite-population association statistic, not a variance of N4.
